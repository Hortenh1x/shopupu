# Исправления аудита, демонстрационный режим и немецкая локализация — план 1.1

> Выполняется в текущей сессии по навыкам subagent-driven-development / executing-plans, с регрессионными тестами и отдельным ревью существенных изменений.

**Цель:** устранить найденные дефекты обоих приложений, подготовить требующие участия владельца интеграции, обеспечить честный демонстрационный checkout и завершённый интерфейс EN/DE.

**Основание одобрения:** 12 сентября 2026, прямое сообщение владельца «исправь все ошибки», с исключением фактического подключения сервисов, требующих его действий, и дополнениями о вымышленных товарах, Stripe test mode и немецком языке. Это одобряет обязательные Q-01–19 исходного аудита с указанным изменением результата. Не даёт разрешения на реальные списания, публикацию, отправку писем/оповещений, отзыв рабочих ключей или разрушительную миграцию рабочей БД. Эти внешние шаги получают готовые инструкции и сохраняют отдельный статус.

**Архитектура:** сохраняются Spring Boot modular monolith и Next.js storefront/admin. Платёжные/сессионные переходы сериализуются на границе PostgreSQL; внешние HTTP остаются вне транзакций. Приватные браузерные данные и незавершённые запросы привязываются к поколению сессии. Демонстрационный режим явно отделяет локальную симуляцию от Stripe sandbox и запрещает live payments. Локализация использует общие словари EN/DE, выбранный язык и единое форматирование; перевод выполняется после основных исправлений.

**Стек:** Java 25 / Spring Boot 4, PostgreSQL + Flyway, JUnit/Mockito/Testcontainers; Next.js/React/TypeScript/TanStack Query, Vitest/Playwright. Поддерживаемые исправленные зависимости выбираются по проверенной совместимости.

## Критерии нового результата

1. Оба подтверждённых P0 не воспроизводятся через API и браузер, включая поздний ответ после смены аккаунта.
2. Один business transition даёт ровно один SALE/RESTOCK; платёж, заказ и резерв согласованы при повторах, конкуренции и сбоях.
3. Публичный режим не позволяет реальные продажи/списания; вымышленные товары и отзывы обозначены без необходимости искать информацию в footer. Stripe доступен исключительно после тестового подключения; до этого UI точно обозначает локальную симуляцию.
4. Независимые от владельца работы закончены и проверены. Необходимые внешние настройки описаны точными шагами, без секретов и ложного статуса «подключено».
5. EN/DE покрывают интерфейс целиком, включая административную часть, подтверждения, ошибки и демонстрационные уведомления. Выбор сохраняется, форматирование и `lang` соответствуют языку.
6. Общий framework и шаблон не переписываются; P2 без связи с найденным дефектом или новыми прямыми требованиями не реализуются автоматически.
